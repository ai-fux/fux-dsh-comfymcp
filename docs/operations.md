# dsh-comfymcp 操作手册

> 面向日常使用与运维。部署先行：[部署文档](deployment.md)。
> 版本 v0.2.0（2026-10-13 封板）：新增图形工作台、成果物库、异步运行与超时中断、标签与提示词体系。

## 0. 图形工作台（v0.2.0）

侧栏点「**ComfyUI 工作台**」→ 中央面板；浏览器亦可直开 `http://127.0.0.1:18801/ui`（控制端点会自动探测端口）。
**顶部 Tab 只有一套**：由客户端插件渲染（我的工作流 / 模板 / 成果物 / 指令），内嵌的静态页在 iframe 里不再重复页头与 Tab；
只有「在新窗口打开 ↗」独立访问时才由页面自己补出标题与 Tab（`window.self === window.top` 判定），保证单独打开仍有导航。
页面内容区第一行即主操作（检索框 / 指令工具栏），说明行与摘要并入工具栏，不占额外行高。

| Tab | 怎么用 |
| --- | --- |
| **我的工作流** | 列出本地工作流（`<主目录>/workflows` + 你配置的工作流目录）。打开即渲染表单；若该工作流跑过，表单会**带出上次运行的参数**（字段标「上次」并高亮，顶部有提示条），点「↻ 重新解析」可回到文件原值 |
| **模板** | 远端模板库。点开任一条目 → 表单 → 点「▶ 执行工作流」**执行一次即自动保存到「我的工作流」**（保存的是可执行 API 图），之后从「我的工作流」进入 |
| **成果物** | 成果物库：卡片样式（瀑布流 / 两列平铺 / 重叠摊开，选择会被记住）、复合检索、勾选批量删除、导出 JSON |

### 工作流页：执行与进度

1. 表单按节点分组（形如 `KSampler (76:69)`，括号内是节点 id）；提示词类字段是**大域 textarea**，自动增高，点「⤢ 展开」可在大窗口看/改全文
2. 点「▶ 执行工作流」→ 按钮转圈并禁用，出现进度条（阶段 + `step/total` + 节点 + 已用时长 + promptId）
3. 执行中可点「**■ 中断执行**」（同时请求取消队列任务）
4. 超过设置里的「**单工作流最大运行时间（分钟）**」→ 自动中断并提示（默认 30 分钟，0/留空＝不限）
5. 完成后成果按运行**分组展示**：每组含状态/种子/用时/时间、正负提示词（悬浮看全文、箭头展开）、可展开的**参数表**；点缩略图可放大（图片支持滚轮缩放 / 拖拽 / 双击切换，视频音频就地播放）

### 成果物库：检索 / 删除 / 导出

- **复合检索**（单输入框；空格＝与、`|`＝或、前缀 `-`＝排除）：

  | 写法 | 含义 |
  | --- | --- |
  | `fashion` | 模糊匹配：正/负提示词、文件名、标签/集合、动态字段名值、参数名值 |
  | `a \| b` | 含 a 或含 b |
  | `tag:夕阳 tag:旅拍` | 同时带这两个标签/集合 |
  | `param:steps>=25`、`param:sampler_name=euler` | 运行参数比较（`= != ~ > >= < <=`） |
  | `field:尺寸~768` | 动态字段 |
  | `prompt:"sunset beach"` | 只在提示词里找（含空格的値用引号） |
  | `file:.png`、`name:image_z`、`state:completed`、`seed:123`、`kind:image` | 文件名 / 工作流名 / 状态 / 种子 / 类型 |
  | `-tag:废片` | 排除 |

  点页面「**? 语法**」可展开速查表，并有 4 个**可点击示例**直接填入检索
- **删除**：卡片右上角「✕ 删除」（记录 + 删盘，二次确认）；勾选（可整组勾选）后「🗑 删除选中」批量删除；产物被清空的组自动移除（无模态数据不入库）
- **导出**：「⇩ 导出该次 JSON」或「⇩ 导出全部（JSON / base64）」→ 下载含当前已有字段（运行信息、提示词正负、标签/集合/动态字段）+ **文件字节 base64 内嵌**的 JSON
- **标签**：卡片上可「＋标签 / 标签集合 / 🗃 集合 / 字段 / 绑定提示词 / 来源」；成果物页提示词旁「⇢ 赋值」可把该提示词回填到工作流表单对应字段

## 1. 日常使用：自然语言生成工作流

在 DSH 会话里用自然语言下达生成需求，模型会走固定管线（技能
`comfymcp-generation-flow` 约束流程）：

```
状态检查 → 空间/模板检索 → 设计工作流（先联网检索资料）
  → 推送定制表单（GUI 弹窗）→ 按答复回填生成可运行图
  → 强制保存到工作流空间 → 执行 → 成果物回显（产物卡）
```

你只需要做两件事：

1. **答表单**：弹出的结构化表单含提示词、数值参数、模型选择、种子。
   种子三选一：使用推送时已随机的种子 / 重新随机 / 手填固定值；
   任何手填值（custom）优先于预设。
2. **看产物卡**：运行完成后会话内出现产物卡——状态色条（绿=完成/红=失败/橙=运行中）、
   图片瓦片网格（点击原图）、文件胶囊、保存位置与种子元信息。

### 每次运行发生了什么

- 工作流**先保存**到 `workflowDirs` 下的 `saveSubdir`（默认 `dsh-generated`）再执行，可回溯；
- 若设置页开启「自动卸载」且服务端支持，运行图会在终点节点前插桩
  `UnloadAllModels`（上游输出 → value → 原消费者），跑完即释放显存；
- 产物经 `/api/comfymcp/artifact?path=` 回显（仅 artifactsDir/工作流空间内，containment 校验）。

## 2. 设置页操作（DSH Web → 设置 → ComfyUI MCP）

| 分区 | 字段/操作 | 说明 |
| --- | --- | --- |
| 头部 | 连接状态点 | 绿=已连接；红=探测失败（附原因与「重新探测」）；灰=尚未探测 |
| 连接 | comfy-mcp 服务端点 | 改后「保存配置」即时生效；「测试连接」随时探测 |
| 连接 | 宿主入口 / 桥接版本 | 只读行，带复制按钮 |
| 工作流空间 | 工作流目录（分号分隔） | 模板检索与强制保存的根 |
| 工作流空间 | 生成保存子目录 | 每次运行先落盘的位置 |
| 工作流空间 | 产物下载目录 | 留空用 DSH 数据目录 |
| 宿主与卸载 | MCP 宿主入口 | 留空走环境变量（仅内置/stdio 模式需要） |
| 宿主与卸载 | 自动卸载开关 | 三态：未连接=禁用；服务端无 UnloadAllModels=禁用+原因；可用=品牌色可切换。**开启＝跨工作流生成时跑完释放显存（输出链插入 UnloadAllModels）；关闭＝同一工作流连续生成（抽卡）不卸载——运行前自动移除工作流自带的 UnloadAllModels 节点**（例如 image_z_image 这类自带卸载节点的工作流），保存/执行的图不含卸载节点，模型热加载生效；运行卡片「⏏ 卸载：…（开关＝开/关）」显示实际处置（已移除 N 个节点 / 未启用 / 已插入） |
| 表单自动确认 | 倒计时自动采用推荐参数 | 默认关＝表单一直等待用户作答；开启后**提问卡片右上角自带可见倒计时**（默认 30 秒，可改，缺省/非法值一律按 30 秒）：①参数表单（comfymcp_push_form）经 seam 计时提问，超时自动采用推荐参数（种子沿用推送时随机值、其余保持推导值）继续执行；②所有 ask_user_question 卡片同样计时（preset 覆盖 `dsh-preset-timed-ask`：tool-ask-user `mode:timed, timeout:30`），到期返回 pending——模型按推荐项继续，**问题仍可后答**，迟到回答以用户消息送达。策略关闭时生成流技能会指示模型传 `timeout:-1` 恢复阻塞等待 |
| 业务配置（第 5 个 Tab） | 首次生成的工作流选择 | **开工先查业务配置，不再每次大海捞针**：模型调 `comfymcp_business`（action=match，传用户原话）→ 命中就直接用该业务类配置里的工作流与默认参数（本地 API 图会连 `graph` 一起返回，省一次取图），**跳过** `comfymcp_discover` 与 `list_models`；没命中才走完整探索流程，跑通后 `action=register` 把结果登记回来（下次即命中）。业务类：文生图 / 图生图 / 文生视频 / 图生视频 / 局部重绘 / 放大 / 音频 / 其它 |
| 业务配置（第 5 个 Tab） | 自动登记与手动配置 | 工作台每**跑过一次**工作流就按图内容自动判定业务类并建档（同业务类已有主配置时不抢占，只把新工作流记进候选，页顶「已跑过但还没登记的工作流」一行一个「登记为…」按钮可一键切换首选）。也可手动「＋ 新增业务配置」：业务类下拉 / 显示名 / 首选工作流（带已有工作流提示）/ 触发词（逗号分隔，命中靠它）/ 参数覆盖（采样步数 / 宽 / 高 / 生成数 / 模型）/ 备注，保存即生效（`<数据目录>/business.json`）。卡片页脚显示用过多少次、最近使用与「自动登记 / 手动」来源 |
| 业务配置（第 5 个 Tab） | 业务类可动态增删 | **业务类不写死**：与配置一起落盘（`business.json` 的 `kinds`，首次读取用内置预置类播种）。页面顶部一行 chip 列出当前全部业务类，点 ✕ 删除（仍被配置引用时拒绝并说明原因），右侧填「名称 + 触发词」点「＋ 添加业务类」即时新增；卡片下拉与模型匹配都用这份清单。例：加「换脸 / 触发词 换脸、faceswap」后，说「把这张照片换脸」即命中该配置。工具侧也能用 `comfymcp_business action=kind_save / kind_remove` 增删 |
| 指令（第 4 个 Tab） | 快捷指令管理 | 工作台顶部「指令」Tab（/ui/commands）**卡片式**编辑：每条指令一张卡（名称 / 标签 / 生成数 / 模式 / 种子策略，**按策略只显示相关参数**），增删卡后「保存指令」即时生效（不再手写 JSON）；每张卡「▶ 执行」沿用最近一次成功运行的参数直接跑 |
| 指令（第 4 个 Tab） | 生成数与模式 | 缺省 1。**连续 N 次**＝每次重滚种子串行跑 N 次（第 1 次立即启动，其余后台链式补跑，页面可关闭）；**批次 1 次**＝直接把工作流 `batch_size` 改为 N 一次执行出 N 张（图中无 batch_size 字段时提示改用连续） |
| 成果物（第 3 个 Tab） | 画廊排布 | 成果物/指令页为**全宽左对齐**（不再套 860px 居中容器）；「瀑布流」为 JS 真瀑布流：固定列宽 300px 算列数，**按列序轮转填充**（第 1 排左→右，第 2 排仍从第 1 列开始），因此不会出现「中间插一张、左侧空一片」；「两列平铺」按最小卡宽 300px 自动铺满；「重叠摊开」保持扇形堆叠 |
| 成果物（第 3 个 Tab） | 卡片内容 | **一次运行＝一张卡**，内部四区用发丝线分隔：①卡片头＝勾选 + 工作流名 + 状态 + 元信息（种子 · 用时 · 件数，单行右侧省略，完整信息含时间在悬浮提示里）；②提示词一行省略、可展开（正/负 + ⇢ 赋值）；③媒体 1:1 满宽，勾选框浮在图左上角（不再占一行高度）；④文件区＝文件名 + 标签/集合/字段 chip（最多 3/2 个，其余折叠为 `+n`，悬浮看全）+ 操作。操作为主次两档：常看的「＋标签 / ⬇下载 / ✕删除」始终显示，「⋯ 更多」就地展开标签集合/集合/字段/绑定提示词/来源/导出 JSON |
| 成果物（第 3 个 Tab） | 多图收集卡与子级画廊 | 同一次运行出 **≥2 张**时合成一张**收集卡**（尺寸与单卡一致）：媒体区把最多 **5 张**按小角度扑克摊开（±7°，悬浮再展开一点），角标「N 张 · 另 K」；点任意一张进入**灯箱子级画廊**——标题 `名字 · 2/5`、底部缩略条高亮、`← →` 或点缩略条逐张切换，逐张仍是同一套缩放/平移/下载工具；「☰ 文件列表」可就地展开完整列表（逐张的标签/下载/删除都在里面） |
| 成果物（第 3 个 Tab） | 视频与音频封面 | **视频＝首帧**当封面（`<video muted preload=metadata src=…#t=0.1>` + ▶ 角标），点开在灯箱里正常播放；**音频＝固定音乐封面**（渐变底 + 波形条 + ♪ 音符，不依赖磁盘缩略图），点开在灯箱里播放 |
| 参数确认框 | 题面自带三件事 | 每页 header＝「用途标题 · 1/N」（模型通过 `comfymcp_push_form` 的 `title` 传入，如「白色机甲 · 生成参数」）；字段名中文化（提示词/采样步数/生成张数/采样器…，技术类名在括号里）；题面写明**推荐值**，选项首位标 `（推荐）`；每页都写倒计时规则「⏱ N 秒未答 → 自动采用【推荐】值继续（本框可留空）」 |
| 参数确认框 | 取消与倒计时 | 用户关掉确认框（放弃整组问题）→ 返回 `cancelled:true`，**不会**再弹一个没有倒计时的对话框；模型应停止执行并询问要改什么，重新推送的表单会带全新倒计时。计时提问的前置失败（非活跃根代理/重复等待）才回退本地竞速，倒计时照常生效 |
| 成果物/工作流 | 点击图片放大 | **整屏遮罩灯箱**：遮罩铺满整个浏览器窗口，图片在遮罩区域内缩放平移（超出部分被裁掉），打开即「适应窗口」；滚轮以光标为锚点缩放、按住拖拽平移、双击切换 适应/1:1、`+`/`-`/`0`/`1` 快捷键、`Esc` 或点空白关闭（拖拽过则不算点击）；右上角圆形 ✕（距上/右各 16px，含滚动条补偿，✕ 在圆内居中），底部工具条含 −/百分比/＋/适应窗口/1:1/新窗口打开/下载；视频音频同一遮罩内就地播放；打开期间锁页面滚动 |
| 底部 | 保存配置 | 有未保存改动时按钮高亮 + 黄色提示；保存写入覆盖层并即时生效 |

## 3. 运维操作

### 3.1 服务启停（PowerShell）

**内嵌模式（默认）**：comfy-mcp 服务端随 DSH 插件自动拉起/回收（随机端口），无需手动启停；
首次使用时日志出现 `embedded comfy-mcp server at http://127.0.0.1:<port>/mcp`。

**外置模式**（设置页关闭内嵌开关后）：

```powershell
$env:COMFY_MCP_BACKEND='mock'; $env:COMFY_MCP_SERVER_PORT='18800'
node comfy-mcp-server\bin\comfy-mcp-server.mjs
# 停止：Ctrl-C；DSH 插件在下次调用时按新状态重连
```

### 3.2 插件代码热迭代

```
改代码 → pnpm --filter dsh-comfymcp-client test → install_bundle → 重启 DSH
```

Client 半区（设置页/产物卡）随浏览器产物构建刷新，页面刷新即可见；
Host 半区（工具/面板通道）受模块快照冻结约束，**必须重启**。

### 3.3 运行历史与产物

- 运行历史存内存（最近 50 条），DSH/插件进程重启即清空（MVP 行为）；
- 产物文件落盘在「产物下载目录」或 DSH 数据目录，历史保存的工作流在
  `workflowDirs/<saveSubdir>/`，可随时打开复跑。

## 4. 故障排查

| 症状 | 原因 | 处置 |
| --- | --- | --- |
| 启动告警 `1 entry did not activate` | 模块快照冻结（改码后未重启）或激活期异常 | 看堆栈行号是否旧代码 → 重启 DSH；仍复现则按堆栈定位 |
| 启动有 `cannot get property "webServer"` | 面板通道在 webServer 落位前注册 | 已内置就绪重试；出现即说明运行的是旧代码，重启装载新版 |
| 设置页显示「connection RPC 不可用」 | 面板通道未挂上（服务端未启动/旧代码） | 确认启动日志有 `panel channel /comfymcp ready`；没有则按上两行处理 |
| 设置页全部读写失败（测试不行/保存失败） | 静态挂载拿不到 connection RPC（平台限制）；环回控制端点未启动 | 看启动日志 `设置页通道就绪：http://127.0.0.1:18801`；没有则说明运行旧代码，重启 DSH |
| `comfymcp_status` ok:false | comfy-mcp 服务端没起 / 端点错 | 内置模式：看日志有无 `embedded comfy-mcp server at <url>`；远程模式：起 18800 服务端后核对 endpoint |
| 内嵌启动失败 `内嵌服务端…未报告监听地址/入口不存在` | 服务入口不对或服务自身崩了 | 服务端已内置（vendor 包）；env `DSH_COMFYMCP_SERVER_ENTRY` 覆盖时核对该路径；手动 `node <插件目录>\vendor\comfy-mcp-server.mjs --selftest` 验证 |
| 卸载开关置灰 | 未连接，或服务端无 UnloadAllModels | 接通后自动可用；真实模式按部署文档 §5 验证 object_info |
| 运行报 ComfyUI 相关错误 | ComfyUI 未运行/显存不足/图不合法 | 查 :8000 存活；看 ComfyUI 控制台输出；开自动卸载释放显存 |
| 产物卡图片裂图 / 404 | 产物不在 containment 目录内 | 核对「产物下载目录」与运行输出目录一致 |
| 表单没弹出来 | userQuestions 服务不可用 | 工具会显式报错；检查 DSH 表单服务启用状态 |

### 日志在哪

- DSH 插件侧：DSH 进程控制台（前缀 `[dsh-comfymcp-client]`，含 MCP 宿主 stdio 透传日志）；
- comfy-mcp 服务端：其自身控制台（启动即打印 backend 模式与端口）；
- ComfyUI：其控制台（卸载节点执行时打印 `Unload Model: - Unloading all models...`）。

## 5. 验收用 E2E 脚本化清单
