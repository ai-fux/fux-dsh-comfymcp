## 1. 主题与目标

**0.6.0 = ComfyUI 工作流引擎之外的「直连多模态创作引擎」。**

工作台新增「创作」页：用户可配置多家多模态服务商（魔搭 ModelScope、HuggingFace、自建 vLLM / Ollama、
A1111/ComfyUI 网关、OpenAI 兼容网关等），用**文生图 / 图生图**直接完成内容创作；成果自动落盘、
进创作历史、可一键作为 img2img 工作流的输入素材。模型侧新增 `comfymcp_create` 工具，
让「帮我画一张封面」在无工作流时也能直达出图。

**双引擎定位**（技能里写死判定规则）：

| 场景 | 引擎 |
| --- | --- |
| 快速出图、封面/草图/灵感、单图编辑（图生图）、没有现成工作流 | **创作台（provider 直连）** |
| 复杂节点链（ControlNet/LoRA/放大/视频）、批量参数、业务配置沉淀 | **ComfyUI 工作流（现有链路）** |

### 适配器能力矩阵（0.6.0 一手实测 + 官方文档）

| kind | 代表平台 | 文生图 | 图生图 | 异步任务 | 说明 |

## 4. 关键技术设计

### 4.1 服务商配置（providers.json）

```jsonc
{
  "version": 1,
  "defaultId": "ms-qwen-image",
  "providers": [
    {
      "id": "ms-qwen-image",
      "label": "魔搭 · Qwen-Image",
      "kind": "modelscope",              // modelscope | huggingface | openai-images | ollama | sdwebui | vllm
      "baseUrl": "https://api-inference.modelscope.cn",
      "apiKey": "env:MODELSCOPE_API_KEY", // 也接受明文（UI 掩码回显，不推荐）
      "model": "Qwen/Qwen-Image",
      "enabled": true,
      "capabilities": ["t2i", "i2i"],
      "defaults": { "size": "1024x1024", "negativePrompt": "", "steps": 30, "guidance": 4, "seed": -1 },
      "timeoutMs": 600000,
      "allowPrivateHosts": false          // 本机 vLLM/Ollama 显式打开
    }
  ]
}
```

- **读取**：`store.list()` 返回脱敏副本（key → `sk-****abcd`）；只有服务端内部解析真实值。
- **写入**：整文件原子写（tmp+rename），校验失败拒绝；`env:VAR` 原样保存，回显时标「环境变量」。
- **安全**：`http(s)` 仅；`allowPrivateHosts=false` 时拒绝 `localhost/127./10./192.168./172.16-31/::1` 等私网目标（SSRF 防护）；本机服务（Ollama/vLLM）建预设时自动置 true。

### 4.2 适配器统一契约

```js
// 每个 adapter 导出
export const kind = 'modelscope'
export function validate(provider) // 结构校验
export async function generate(provider, request, deps = { fetchImpl, abortSignal, onProgress })
// request: { mode:'t2i'|'i2i', prompt, negativePrompt?, size?, steps?, guidance?, seed?, n?, image?{b64,mime}|{url} }
// 返回: { images: [{ b64, mime, revisedPrompt? }], raw?, taskId?, elapsedMs }
```

- **modelscope**：`POST {base}/v1/images/generations`（带 `X-ModelScope-Async-Mode:true`，body 含 `image_url` 时走图生图）→ `task_id` → 轮询 `GET {base}/v1/tasks/{id}`（`X-ModelScope-Task-Type:image_generation`）→ `output_images` 下载。
- **openai-images**：同步 `POST {base}/images/generations`（`response_format:'b64_json'` 优先，失败回退 url 下载）；图生图 `POST {base}/images/edits`（multipart）；若响应含 `task_id` 且配置开启异步 → 轮询 `{base}/tasks/{id}`。
- **huggingface**：默认 base `https://router.huggingface.co/v1`；model 缺省 `stabilityai/stable-diffusion-xl-base-1.0`；响应 `data[].b64_json|url`。
- **ollama**：openai-images 协议 + 默认 base `http://localhost:11434/v1` + 标 `experimental:true`（UI 提示 macOS/MLX 限制）。
- **sdwebui**：`POST /sdapi/v1/txt2img` / `/sdapi/v1/img2img`（`init_images` b64、`denoising_strength`、`cfg_scale`、`sampler_name` 可配）；响应 `images[]` b64。
- 所有 adapter：错误统一 `{ ok:false, error, code, status? }` 抛 `ProviderError`；401/403 →「密钥无效或无权限」；429 →「限流，稍后重试」；超时 →「服务商响应超时（{ms}ms）」。

### 4.3 创作任务流（异步）

```
POST /api/create { providerId, mode, prompt, ..., image? }
  → 创建 job（内存队列 + creations.json 记录草稿）→ 立即返回 { jobId }
GET  /api/create/job/{id} → { status: running|succeeded|failed, elapsedMs, images:[{path,url}], error }
```
- 长任务（魔搭 FLUX 可达数分钟）不阻塞 HTTP；页面轮询 1.5s，页面关闭任务继续（服务端跑完落盘）。
- 每个 job 存 `abortController`；`POST /api/create/job/{id}/cancel` 取消。
- 完成后图片写盘 → `creations.json` 记完成态 → 页面刷新画廊。**进度**：魔搭能拿到 `task_status` 轮询，暂不解析 step 级进度（Ollama stream 有 step，P1 可加）。

### 4.4 页面结构（/ui/create）

- **顶部 Tab**：沿用 `workbenchTabs`，新增「创作」。
- **区块 1 · 服务商**：卡片列表（启用开关 / 编辑 / 删除 / 测试）；「＋ 添加服务商」弹层：预设模板（魔搭 Qwen-Image / HF SDXL / Ollama Z-Image / vLLM-omni / A1111 / 自定义）→ 自动填 baseUrl/model → 用户补 API key → 保存。测试：对 OpenAI 兼容 kinds 调 `GET {base}/models`，对魔搭调一次轻量任务探测；结果标 🟢/🔴 + 说明。
- **区块 2 · 创作**：服务商下拉（含启用态）→ 模型输入（可手填，预置默认值）→ 模式切换 文生图/图生图（图生图出现图片来源：上传 / 从成果物选择 / 粘贴 URL）→ 提示词（正/负）→ 尺寸/步数/引导/种子（折叠「高级」）→ 生成。
- **区块 3 · 结果**：画廊瓦片（复用 lightbox 预览）；每张：下载 / 复制提示词 / 再来一张 / 作为工作流输入（P1）/ 删除；进行中显示骨架 + 耗时。
- **区块 4 · 创作历史**：最近 20 条（时间、服务商、模型、提示词摘要、缩略图、状态、重试按钮）。

### 4.5 工具 `comfymcp_create`

```
comfymcp_create
  action: 'generate' | 'providers' | 'history'
  provider?        // 缺省用 defaultId
  mode: 't2i' | 'i2i'
  prompt: string   // 必填（generate 时）
  negativePrompt?, size?, steps?, guidance?, seed?, n?
  image?           // 图生图：本地绝对路径 | 成果物文件名 | http(s) URL
```
返回：`{ ok, jobId, images: [{ path, url, provider, model, size }], elapsedMs, hint }`。
`hint` 引导模型：结果已落盘并出现在工作台「创作」页；需要继续编辑可再来一张（改 seed/prompt），或把该图作为 img2img 工作流输入。
错误：`{ ok:false, error, code }`（401/403/429/超时/未配置服务商）。

## 6. 风险与开放问题

1. **魔搭异步强依赖**：Qwen-Image 等大模型必须异步（`X-ModelScope-Async-Mode`），同步会超时——适配器默认异步，超时上限 600s 可配。
2. **Ollama 实验性**：macOS/MLX 先行，Windows/Linux 未支持；UI 标「实验性」且测试连接给出平台提示。不当成承诺。
3. **vLLM**：原生不产图；需 vllm-omni 或外挂 OpenAI 网关。preset 里标「vLLM-omni」。
4. **零依赖约束**：适配器只用 Node 内置 fetch；图片处理只用 magic bytes 判型，不做缩略图（浏览器缩放即可）。
5. **密钥安全**：明文落盘不可避免（插件无系统密钥库），以 `env:VAR` 为首选并文档化；掩码回显防窥屏。
6. **包体积**：新增代码预计 ~60–80KB JS（页面占大头）；`npm pack --dry-run` 复核 files 白名单。
7. **ComfyUI 与 provider 结果并存**：创作记录独立 `creations.json`，避免污染 runs.json；P1 再入成果物检索。
8. **网络**：provider 请求走用户机器直连（魔搭 api-inference 国内可直连；HF router 可能需要代理——错误提示里给出「检查网络/代理」）。
